In the general settings (debug mode), "API key expiration warning":

- the group whose members get the To Do (the system administrators by
  default). The members need read access to the API keys, the others are
  skipped and a warning is logged.
- how many days before the expiration of a key they are warned (15 by
  default). 0 disables the warnings.

The To Do is created by a scheduled action, run daily.
